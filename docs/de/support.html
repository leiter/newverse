Häufig gestellte Fragen

Allgemein

F: Was ist Bodenschätze?

Bodenschätze ist eine Marktplatz-App, die Kunden mit lokalen Anbietern und regionalen Produkten in ihrer Nähe verbindet.

F: Ist die Nutzung von Bodenschätze kostenlos?

Ja, Bodenschätze kann von Kunden kostenlos heruntergeladen und genutzt werden.

F: Auf welchen Plattformen ist Bodenschätze verfügbar?

Bodenschätze ist für iOS (App Store) und Android (Google Play Store) verfügbar.

Für Kunden

F: Wie gebe ich eine Bestellung auf?

Durchsuchen Sie Produkte von lokalen Anbietern, legen Sie Artikel in Ihren Warenkorb und gehen Sie zur Kasse. Sie erhalten eine Bestätigung mit Abholdetails.

F: Wann kann ich meine Bestellung abholen?

Die Abholung ist für Donnerstage geplant. Bestellungen, die bis Dienstag 23:59 Uhr aufgegeben werden, können in derselben Woche abgeholt werden. Spätere Bestellungen werden für den folgenden Donnerstag eingeplant.

F: Kann ich meine Bestellung nach dem Aufgeben ändern?

Ja, Sie können Ihre Bestellung bis Dienstag 23:59 Uhr vor Ihrem geplanten Abholtag bearbeiten.

Für Verkäufer

F: Wie werde ich Verkäufer auf Bodenschätze?

Kontaktieren Sie uns unter der unten stehenden E-Mail-Adresse, um zu erfahren, wie Sie Anbieter auf Bodenschätze werden können.

F: Wie füge ich Produkte zu meinem Inventar hinzu?

Verwenden Sie die Funktion "Produkt erstellen" in der Verkäufer-App, um neue Produkte mit Fotos, Beschreibungen und Preisen hinzuzufügen.

Problem melden

Wenn Sie einen Fehler oder ein technisches Problem feststellen:

  1. Notieren Sie die genauen Schritte, die zum Problem geführt haben
  2. Machen Sie wenn möglich einen Screenshot
  3. Geben Sie Ihr Gerätemodell und Ihre Betriebssystemversion an
  4. Senden Sie uns eine E-Mail an die oben genannte Support-Adresse

Konto löschen

So löschen Sie Ihr Konto und die zugehörigen Daten:

  1. Öffnen Sie die App
  2. Gehen Sie zu den Profileinstellungen
  3. Wählen Sie "Konto löschen"
  4. Bestätigen Sie Ihre Auswahl

Oder kontaktieren Sie uns unter bodenschaetze@cutthecrap.link, um die Löschung Ihres Kontos zu beantragen.
